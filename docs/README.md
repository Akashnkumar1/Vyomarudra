## The One Design Principle

> Every mystical-sounding idea must either (a) reduce to a known, proven technique we can build today, or (b) be isolated as a cheap, falsifiable Phase-0 experiment. Nothing speculative sits on the critical path. **Vision bada rakho, bets chhote rakho.**
